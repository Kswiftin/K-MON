# Contributing to Pokédoro

**English** · [한국어](CONTRIBUTING.ko.md) · [日本語](CONTRIBUTING.ja.md)

Bug reports, feature proposals, code, tests, and documentation improvements are welcome. The canonical guides are maintained in Korean:

- [Contribution guide](docs/community/contributing.md): issues, pull requests, working language, and contribution terms.
- [Development setup](docs/development/setup.md) and [conventions](docs/development/conventions.md): builds, tests, CI, and change guidelines.
- [Governance](GOVERNANCE.md), [code of conduct](CODE_OF_CONDUCT.md), and [security reporting](SECURITY.md).

PR titles, bodies, and commit messages use Korean. If another language is easier, submit in that language and let us know; a maintainer will translate the title before merging. Code identifiers, API names, CLI commands, and error strings remain unchanged.

Before contributing code or assets, read the [contribution terms](docs/community/contributing.md#기여-자료와-라이선스), [MIT License](LICENSE), and [third-party notices](THIRD_PARTY_NOTICES.md).
