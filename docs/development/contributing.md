# 함께 개발하기

Pokédoro는 팀 동료들과 재미로 만드는 비상업 팬 프로젝트입니다. 앱의 공개 이름은 Pokédoro이고 소스 패키지는 `PokeTokenBar`입니다.

## 변경 보내기

1. `main`에서 작업 브랜치를 만들고 한 가지 변경에 집중합니다.
2. [개발 환경](setup.md)과 [개발 규약](conventions.md)을 참고해 변경하고 검증합니다.
3. `main`을 대상으로 PR을 열어 무엇을 왜 바꿨는지, 확인한 결과를 적습니다. 동작이 바뀌면 관련 테스트와 문서도 갱신합니다.
4. 팀 동료와 리뷰하고 CI 결과를 확인한 뒤 squash merge합니다.

버그나 아이디어는 팀에서 이야기하거나 [이슈](https://github.com/Kswiftin/K-MON/issues)에 남깁니다. 버그는 앱·macOS 버전과 재현 방법을 함께 적으면 확인하기 쉽습니다.

## 작업 언어

PR 제목·본문, 커밋 메시지, 코드 주석과 문서는 한국어로 씁니다. 제목은 `feat:`, `fix:`, `docs:` 등 접두어 뒤에 변경 의도를 적습니다. squash merge 후 PR 제목이 `main` 커밋 제목이 됩니다. 다른 언어가 편하면 그대로 제출하고 알려 주세요. 머지 전에 제목을 한국어로 정리합니다. 코드 식별자·API 이름·CLI 명령·에러 문자열은 원문을 유지합니다.
