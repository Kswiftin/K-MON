# Memory Home 고도화 계획 (기획서 27항 → 이 앱의 범위)

원본 기획서는 `docs/product/pokemon-my-mini-home-idea.md` 다(추적되지 않는 경로 —
`.gitignore` 가 `docs/product/` 를 무시한다. 그래서 **결정과 근거는 이 문서에** 남긴다).

## 이 앱은 기획서의 어느 부분을 할 수 있나

기획서는 오픈월드 생활형 RPG 를 상정한다. 이 앱은 **메뉴바 포모도로 + 동행**이다. 그래서
"동네를 걷는다·야생을 만난다·NPC 와 교환한다" 계열(§2 §6 §7 §21 §22 §23 §26)은 새 게임을
만드는 일이고, 이 계획의 범위가 아니다.

범위 안은 기획서 §27 이 스스로 고른 ★★★★★ 세 개다 — **미니홈피/미니룸 정체성**,
**포켓몬 생활 AI**, **사진/추억 앨범**. 셋 다 이 앱에 이미 데이터가 있다.

## 설계 원칙: 새 저장 필드를 만들지 않는다

이 홈의 기존 코드가 반복해 지키는 규칙이다 — POKÉLOG 는 "read-time view of the existing
album", 계절은 "달력 월에서 파생하므로 저장 필드가 하나도 없다", 일기는 "저장하지 않는다".

파생으로 만들면 (1) 세이브 마이그레이션이 필요 없고 (2) 기존 사용자의 홈이 즉시 풍부해지며
(3) 되돌리기가 삭제 한 번이다. **이 계획의 모든 단계가 파생이다.** 새 `Codable` 키는 0개다.

## 단계

### 0단계 — 도달 불가 기능 복구 (§11 §14 §17 §24 §25)

`eee5c86` 이 팝오버 `MemoryHomeView` 를 창 `MemoryHomeWindowView` 로 옮기면서 일부만 이식했다.
남은 쪽은 `@available(*, deprecated)` + **비-`View`** 로 박제돼, 다음 다섯 기능이 코드에는
있는데 화면에서 사라졌다.

| 기획서 | 기능 | 박제된 위치 |
|---|---|---|
| §11 | 주크박스(대표 BGM) | `setJukeboxTrack` — **UI 가 아예 없었다**(테스트만 호출) |
| §14 | 파도타기 | `MemoryHomeVisitSheet` |
| §17 | 기분 → 동행 반응 문구 | `MemoryHomeMoodStyle.reaction` |
| §24 | 계절 배지 | `MemoryHomeSeasonStyle` |
| §25 | 계절 결산 | `seasonRecap` + `MemoryHomeSeasonRecapSheet` |
| §5 | **방꾸미기 전체** — 스타일 4종·12칸 격자·되돌리기·초기화 | `MemoryHomeView.furnitureRow` |

마지막 줄이 이 결함의 핵심이다. 방꾸미기는 `9de278f` 가 새로 넣은 기능인데, **같은 커밋이
만든 새 창이 아니라 그 커밋이 밀어낸 옛 화면에** 붙었다. 그래서 최신 기능이 한 번도 도달
가능한 적 없이 릴리스됐고, 창에는 legacy 3슬롯만 남아 있었다.

**왜 테스트가 못 걸렀나**: 테스트는 스타일 헬퍼의 세 언어 문구와 앨범 메서드의 지속성을
직접 호출해 검증한다. 둘 다 통과한다 — 호출자가 화면이 아니어도 통과하기 때문이다.
"이 기능에 도달할 수 있는가" 를 묻는 검증이 없었다.

**영구 캡처**: 박제된 `MemoryHomeView` 를 **삭제**했다(약 630줄). 살아 있는 창이 쓰는 시트
둘(스티커 사진·계절 결산)만 남기고, 창이 이미 인라인으로 대체한 시트 셋(POKÉLOG·다이어리·
방문)은 함께 지웠다. 문서나 기억이 아니라 구조로 막는다 — 죽은 두 번째 홈 화면이 없으면
기능이 그쪽에 남는 일 자체가 불가능하다.

더해서 `test-gate.sh` 에 `Sources/PokeTokenBar/UI` 의 `@available(*, deprecated` 를 실패로
만드는 grep 게이트를 넣었다. 테스트로는 못 막는 부류라서다(위 문단 참조).

**§11 은 복구에서 멈추지 않았다.** 곡을 그냥 고르게 하면 기획서가 말한 "음악을 들으면 특정
포켓몬과의 기억이 떠오른다" 가 빠진다. 그래서 `MemoryHomeJukebox` 가 **이미 쌓인 기억으로
해금을 파생**한다 — 집중 10회(비 오는 날의 산책), 여름 기억 1개(여름, 강변), 밤 10시 이후
기억 1개(잠들지 않는 밤). 해금 상태를 저장하지 않으므로 세이브를 옮겨도 같이 따라온다.
오디오는 재생하지 않는다(저작권 음원·재생 권한은 범위 밖).

**부수 발견**: 방꾸미기를 창으로 옮기면서 R7 → R8 이전이 legacy `roomLayout` 을 비우지 않아,
방을 초기화하고 재시작하면 옛 가구가 되살아나는 결함을 찾아 고쳤다. 자세한 내용과 부류는
`defect-log.md` 의 "일회성 이전은 일회성이 아니다" 항목에 있다.

### 1단계 — §5 포켓몬 생활 AI (종 × 가구 반응)

기획서가 ★★★★★ 로 꼽고 예시까지 준 항목인데, 구현은 가구 3종만 보는 문구 3줄이었다
(`roomInteraction`). 종을 아예 보지 않아 "누구의 방이든 같은 문장" 이었다.

`MemoryHomeRoomLife` (순수 함수, 게이트 대상)로 뺀다. 우선순위는 좁은 것부터:

1. **종 × 가구** — 기획서의 짝을 있는 가구로 옮긴다(잠만보+침대 → 침대 독차지,
   피카츄+레트로 TV → 화면 위에서 잠, 고오스+TV → 화면에서 튀어나옴 …).
2. **가구 단독** — 짝이 없는 종의 기존 3줄.
3. **기분** — 가구가 비었으면 §17 반응이 방을 채운다.
4. **계절** — 그것도 없으면 계절 한 줄.

입력은 전부 이미 저장된 값이다: `speciesID`, `placedDecor`, `moodByDayKey`, 달력.

### 2단계 — §13 동행이 방명록에 흔적을 남긴다

`companionGuestbookLine` 은 이미 쓰여 있었지만 호출자가 없었다. 기획서는 "아주 드물게" 라
했으므로 **dayKey 결정론**으로 만든다 — 난수면 열 때마다 다르고, 캡(50개)을 잠식한다.

- 하루 최대 1개. 같은 날 동행 글이 이미 있으면 아무것도 하지 않는다(멱등).
- dayKey 해시로 약 4일에 1번. 같은 날 다시 열어도 결과가 같다.
- 문구는 그날의 기분을 읽는다 — 우울한 날 "오늘 진짜 신났어!" 가 뜨면 §17 을 배신한다.

### 3단계 — §18 계절·기념 추억 카드

카드는 6종(첫 만남·집중·진화·1주년·함께한 N일·방문)뿐이고 전부 "적립" 계열이다.
기획서가 든 예(첫눈·크리스마스)는 **날짜**가 만드는 카드다.

- `firstSnow` — 겨울에 남은 첫 기억. `christmas` — 12/25 에 남은 기억.
- 둘 다 이미 있는 `memories[].createdAt` 만 읽는다. 생일은 넣지 않는다 —
  트레이너 생일을 저장한 적이 없고, 그걸 묻는 것은 이 계획의 "새 필드 0개" 를 깬다.

### 4단계 — §25 연말 결산

기획서가 "대표 기능으로 밀어도 좋다" 고 한 항목인데, 있던 것은 계절 결산뿐이었다.
`yearRecap` 이 한 해를 한 장으로 되돌려 준다 — 만난 동행, 가장 많은 **날**을 함께한 동행,
함께한 날 수, 올해의 기억·사진, 대표 BGM, 그리고 "내년에도 같이 놀자."

- 창은 `dayKey` 의 앞 4글자다. `Date` 산술로 연초/연말을 만들면 타임존·DST 에서 하루가 어긋난다.
- **담지 않은 셋.** 담을 수 없는 것을 담으면 결산이 거짓말을 한다:
  집중 횟수(`completedFocusSessionIDs` 에 날짜가 없다), 기분(`moodByDayKey` 가 60일에서 잘린다),
  기획서의 "가장 자주 방문한 장소"(이 앱에 장소가 없다).
- 자동으로 띄우지 않는다. "올해 한 번만" 판정은 새 저장 필드를 요구하고, 그건 이 계획의
  "새 필드 0개" 를 깬다. RECORDS 탭의 버튼으로 연다.

**같이 고친 결함 3건** (전부 "파생 통계가 라벨과 어긋난다" 부류):

| 무엇 | 어긋남 | 처방 |
|---|---|---|
| `seasonRecap.memoryCount` | 숨긴 기억을 셌다 (`timeline`·`diary`·날짜 카드는 전부 제외하는데) | `!isHidden` 필터 |
| `seasonRecap.mostChosenMood` | 동률에서 딕셔너리 순회 순서를 따라가 호출마다 답이 바뀜(실측) | rawValue 사전 순 타이브레이크 |
| `seasonRecap.focusSessions` | **통산값**이 "이번 계절" 라벨 아래 있었다 | 좁힐 수 없으므로 라벨에 "통산" 을 적음 |

**영구 캡처**: `test-gate.sh` 에 **도달 불가 시트 스윕**을 넣었다 — `MemoryHome*Sheet` 중
아무도 `.sheet` 로 띄우지 않는 타입이 있으면 실패한다. `deprecated` 게이트의 형제다(계절 결산
시트가 정확히 이 형태로 죽어 있었다). 결함을 주입해 실제로 실패하는지 확인했다.
