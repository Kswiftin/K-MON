# 기여 가이드

Pokédoro는 작은 비상업 팬 프로젝트입니다. 버그 보고, 기능 제안, 코드 수정, 테스트와 문서 개선을 환영합니다. 앱과 프로젝트의 공개 이름은 Pokédoro이며 소스 패키지는 `PokeTokenBar`입니다.

## 문의와 제안

먼저 [기존 이슈](https://github.com/Kswiftin/K-MON/issues)를 검색합니다.

| 내용 | 경로 | 포함할 정보 |
| --- | --- | --- |
| 일반 버그 | 버그 보고 이슈 | 앱·macOS 버전, 재현 단계, 기대·실제 결과 |
| 기능·문서 제안 | 기능 제안 이슈 | 해결할 문제, 사용 사례, 제안과 대안 |
| 사용 질문 | 일반 이슈 | 시도한 방법과 막힌 부분 |
| 보안 취약점 | [보안 정책](security.md) | 비공개 경로로 재현 조건과 영향 전달 |
| 행동 규범 위반 | [행동 규범](code-of-conduct.md#신고와-대응) | 지정된 연락 절차 이용 |
| 권리자의 우려 | 일반 이슈 또는 메인테이너 연락 | 관련 파일·배포물과 요청 사항; 민감한 정보는 제외 |

로그나 화면을 공유하기 전에 토큰, 인증 정보, 사용자 이름·경로, 대화와 세이브의 개인 내용을 지워 주세요. 큰 기능이나 저장·통신 형식 변경은 구현 전에 이슈에서 범위를 논의하면 검토 비용을 줄일 수 있습니다.

## PR 절차

1. `main`에서 작업 브랜치를 만듭니다. 쓰기 권한이 없으면 fork를 사용합니다.
2. 한 가지 문제에 집중해 변경합니다. [개발 환경](../development/setup.md)과 [개발 규약](../development/conventions.md)을 따릅니다.
3. 변경에 맞는 검증을 실행하고 관련 사용·개발 문서를 갱신합니다.
4. `main`을 대상으로 PR을 열고 [템플릿](../../.github/PULL_REQUEST_TEMPLATE.md)에 목적, 관련 이슈, 변경 내용, 검증 결과를 적습니다.
5. 리뷰 의견에 답하고 수정 후 필요한 검증을 다시 실행합니다. 메인테이너가 CI와 리뷰를 확인한 뒤 squash merge합니다.

문서만 바꿨다면 링크·이미지 경로·내용 일관성 검증을 적습니다. 코드 변경은 전체 테스트와 관련 게이트 결과를 적고, 환경 제약으로 실행하지 못한 검증도 명시합니다. 정책 변경은 [의사결정 절차](governance.md#의사결정)를 따릅니다.

## 작업 언어와 제목

PR 제목·본문, 커밋 메시지, 코드 주석과 `docs/` 문서는 한국어로 씁니다. 제목은 `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:` 등 Conventional Commits 접두어 뒤에 한국어로 변경 의도를 씁니다. squash merge 후 PR 제목이 `main` 커밋 제목이 됩니다.

다른 언어가 편하면 그 언어로 이슈나 PR을 열고 알려 주세요. 언어만을 이유로 기여를 거절하지 않으며 메인테이너가 머지 전에 제목을 한국어로 옮깁니다. 코드 식별자·API 이름·CLI 명령·에러 문자열은 원문 그대로 둡니다.

## 기여 자료와 라이선스

- 포켓몬 등 제3자의 스프라이트·아트워크·오디오·폰트·대량 이름 및 데이터 파일을 커밋하거나 번들하지 않습니다. 종 데이터와 스프라이트는 런타임에 PokéAPI에서 받아 사용자 기기에 캐시하는 방식을 유지합니다.
- 상업적 사용을 의도하거나 제3자 저작물을 재배포·내보내는 기능을 추가하지 않습니다.
- 비밀값, 인증 정보, 비공개 내부 도구 참조를 커밋하지 않습니다.
- 기여자는 제출물을 제공할 권한이 있어야 하며 프로젝트 소스 기여는 [MIT License](../../LICENSE)를 따릅니다. 제3자 구성 요소에는 해당 라이선스와 [고지](../../THIRD_PARTY_NOTICES.md)를 유지합니다. MIT 라이선스는 제3자의 상표·아트워크·데이터 권리를 부여하지 않습니다.

비공식 팬 프로젝트 안내와 권리 범위는 [데이터·개인정보와 면책](../guides/privacy.md)을 참고하세요. 커뮤니티 참여에는 [행동 규범](code-of-conduct.md)이 적용됩니다.
