# Pokédoro · 포케도로

**뽀모도로 집중과 포켓몬 모험을 결합한 macOS 메뉴바 게임**

[![macOS](https://img.shields.io/badge/macOS-14%2B-0969da)](https://www.apple.com/macos/)
[![Swift](https://img.shields.io/badge/Swift-6-f05138)](https://swift.org)
[![License](https://img.shields.io/badge/license-MIT-3fb950)](LICENSE)

</div>

집중하는 동안 포켓몬 파트너를 모험에 보내고, 보상으로 포켓몬을 수집·육성하는 앱입니다. 평소에는 메뉴바에 `휴식 중` 또는 타이머만 표시됩니다. 앱 화면과 문서의 기본 언어는 한국어입니다.

<p align="center"><img src="assets/screenshot-home.gif" width="220" alt="집중 타이머와 모험 조작이 있는 홈 화면"></p>

## 시작하기

macOS 14 이상에서 Apple Silicon과 Intel을 지원합니다.

1. [릴리스](https://github.com/Kswiftin/K-MON/releases)에서 `Pokedoro.zip`을 내려받습니다.
2. 압축을 풀고 `Pokédoro.app`을 `/Applications`로 옮깁니다.
3. 앱을 열고 25분·50분·90분 중 집중 시간을 고릅니다. 모험이 끝나면 홈에서 보상을 수령합니다.

첫 실행과 권한 설정은 [설치 안내](docs/guides/installation.md)를, 소스 빌드는 [개발 안내](docs/development/setup.md)를 참고하세요.

## 즐길 거리

- **집중과 육성**: 집중 기록·주간 회고, 알 부화, 도감, 파트너 육성, 상점과 가방.
- **대전과 협동**: CPU 연습, LAN 배틀·방 배틀, 체육관, 협동 레이드, 토너먼트, 포켓슬론, 교환과 경매.
- **탐험과 꾸미기**: 웨이브 런, 사파리존, 트레이너 의상, 포코피아 마을.
