# Pokédoro · 포케도로

**포켓몬 수집과 뽀모도로 집중을 결합한 macOS 메뉴바 게임**

[![macOS](https://img.shields.io/badge/macOS-14%2B-0969da)](https://www.apple.com/macos/)
[![Swift](https://img.shields.io/badge/Swift-6-f05138)](https://swift.org)
[![License](https://img.shields.io/badge/license-MIT-3fb950)](LICENSE)

</div>

Pokédoro는 집중하는 동안 포켓몬을 모험에 보내 성장시키고, 수집한 포켓몬으로 배틀과 포켓슬론을 즐기는 메뉴바 앱입니다. 평소에는 메뉴바에 `휴식 중` 또는 타이머만 표시해 업무 환경에서도 자연스럽게 사용할 수 있습니다.

> 비공식·비상업 포켓몬 팬 프로젝트입니다. 포켓몬 데이터와 스프라이트는 런타임에 [PokéAPI](https://pokeapi.co/)에서 불러옵니다.

## 주요 기능

### 집중과 모험

- 25분·50분·90분 뽀모도로를 시작하면 같은 시간의 모험이 진행됩니다.
- 완료한 모험의 보상을 직접 수령할 때만 **경험치**와 **별의조각**을 얻습니다. 긴 집중일수록 보상이 커집니다.
- 경험치는 현재 포켓몬의 레벨을 올리고, 별의조각은 상점 구매와 랭크 배틀 판돈에 사용합니다.
- 모험에서 알 조각을 모을 수 있습니다. 10개를 모으면 알 1개가 되고, 일일 첫 모험과 주간 누적 모험 보너스도 있습니다.
- 일간·주간 **미션**이 홈에 뜹니다. 모험 정산·집중 시간·졸업을 세고, 목표에 닿는 순간 별의조각이 자동으로 들어옵니다.
- 방해금지 모드는 시스템 알림, 플로팅 펫, 배틀 신청 수신을 막습니다.

### 포켓몬과 도감

- 첫 시작에 원하는 타입을 고르면 1세대 미진화 포켓몬 한 마리가 알에서 무작위로 태어납니다. 전설·환상은 제외하며 메타몽은 포함합니다.
- 포켓몬 화면에서 이미지·타입·이름·레벨·다음 레벨 경험치를 확인하고, 소유 포켓몬을 교체할 수 있습니다.
- 본가 기준 종족값·타입·레벨업 기술·진화 레벨을 사용합니다.
- 레벨업으로 기술을 배울 때 수락하거나 거절할 수 있고, 기술이 4개면 잊을 기술을 선택합니다. 진화 전 기술은 그대로 유지됩니다.
- 기술 보기에 마우스를 올리면 본가 기술 설명과 위력·명중률·분류·PP가 표시됩니다.
- 진화 레벨에 도달해도 자동 진화하지 않습니다. 진화 확인에서 `예`를 선택해야 진화하며, `아니오`를 선택하면 다음 레벨에 다시 제안합니다.
- 통신 진화는 연결의끈, 분기·도구 진화는 해당 진화의 돌을 사용합니다.
- 도감은 발견한 종과 이로치 여부를 기록합니다.

### 알과 상점

- 알은 한 종류이며 구매하면 기존 포켓몬을 놓아주지 않고 보유 알에 추가됩니다.
- 알은 상점, 모험의 희귀 보상, 알 조각 및 주간 모험 보상으로 획득합니다.
- 상점에서는 알, 이상한 사탕, 민트, 연결의끈과 진화의 돌을 판매합니다. 이로치 부적은 판매하지 않습니다.
- 이상한 사탕은 현재 포켓몬의 경험치를 즉시 올립니다.

### 배틀

- 같은 로컬 네트워크의 사용자를 Bonjour로 찾아 직접 신청하고 수락하는 방식입니다. 신청 자동 수락은 지원하지 않습니다.
- 랭크 배틀에서는 모든 포켓몬이 Lv.50으로 보정되지만 실제로 배운 기술을 사용합니다.
- 타입 상성, STAB, 물리·특수 종족값, 명중, 급소, PP를 반영합니다.
- 낮은 랭크가 높은 랭크에 도전하면 정해진 단위의 별의조각을 걸며, 승패에 따라 별의조각과 상위 랭크 점수가 이동합니다.
- CPU 연습에서 1대1·3대3·6대6과 포켓몬 교체를 시험할 수 있습니다. 현재 LAN 실전은 1대1입니다.

### 포켓슬론 · 체인지릴레이

- 혼자 연습하거나 로컬 네트워크에서 최대 4명이 한 트랙에서 달릴 수 있습니다.
- `→`로 달리고 `↑`·`↓`로 레인을 바꿔 바위를 피하며, `C`로 포켓몬을 교체합니다.
- 참가자끼리 충돌해도 장애물 충돌로 판정되며, 3·2·1 카운트다운과 전체 순위·결승선 판정을 제공합니다.

## 화면 구성

- **홈** — 현재 파트너, 집중 타이머, 모험과 보상, 일간·주간 미션
- **포켓몬** — 소유 목록, 현재 파트너 교체, 경험치·타입·기술 확인
- **도감** — 발견한 포켓몬 조회
- **배틀** — CPU 연습, LAN 신청·랭크 배틀
- **포켓슬론** — 체인지릴레이 연습 및 멀티플레이

상점과 가방은 별도 버튼으로 엽니다.

## 설치와 빌드

요구 사항은 macOS 14 이상입니다.

```bash
swift build
./scripts/build-app.sh
```

`build-app.sh`는 릴리스 앱을 빌드해 `/Applications/Pokédoro.app`에 설치합니다. 자체 서명 앱이므로 처음 실행할 때 Finder에서 앱을 Control-클릭한 뒤 **열기**를 선택해야 할 수 있습니다. LAN 플레이에는 macOS의 로컬 네트워크 권한이 필요합니다.

> 현재 게임 구조 개편 버전은 이전 버전의 진행 데이터를 최초 실행 시 한 번 초기화합니다. 스타터 선택부터 새로 시작합니다.

## 데이터와 개인정보

- 진행 데이터와 캐시는 `~/Library/Application Support/PokeTokenBar/`에 저장됩니다.
- 배틀과 포켓슬론 연결은 로컬 네트워크에서 피어 투 피어로 동작합니다.
- 종·진화·기술·스프라이트를 위해 PokéAPI와 관련 정적 에셋 서버에 연결합니다.
- 앱에는 Codex·Claude 사용량 연동이나 수집 기능이 없습니다.
